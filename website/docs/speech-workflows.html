03 Speech workflows

Turn research into a speech.

Mark the destination document, send it the evidence you need, and organize the round with speech timing, flows, and argument maps.

01 / Set a destination

Choose a speech document

Tagline sends evidence to a Markdown file designated as a speech document. To mark an existing note:

  1. Right-click the Markdown file in the file explorer.
  2. Choose Set as speech doc. Tagline adds speech: true to its YAML frontmatter without discarding other metadata.
  3. Choose the active destination under Settings > General > Active speech document.
---
speech: true
---

New speech documents include this marker automatically. You can mark multiple files, but only the selected destination receives cards. The configured path is a local preference; if it is unavailable, Tagline uses the first marked file in path order.

02 / Move evidence into a case

Send selected evidence

  1. Open a research note and select the text or evidence card you want to use.
  2. Press Ctrl+Shift+S on Windows/Linux or Cmd+Shift+S on macOS.
  3. Review the active speech document and organize the inserted material into your argument.

The same workflow can send highlighted evidence. Keep source details in the original card so the speech document can be traced back to the research.

Need to create the source citation first? Follow Create a citation.

03 / Check speaking time

Estimate and calibrate a speech

Tagline estimates speaking time from highlighted evidence and citations in a speech document. Personal speech calibration can tune the estimate to your own pace:

  1. Open Settings > General.
  2. Open personal speech calibration.
  3. Use your timed speech samples to adjust the estimate, then compare it with a real practice run.

Use the estimate as a planning aid, then time a full read-through to confirm it works for your delivery.

04 / Plan the round

Use the speech and prep timer

The timer includes speech and affirmative/negative preparation clocks for two policy-debate presets:

HIGH SCHOOL8 · 3 · 5Policy debate preset
COLLEGE9 · 3 · 6Policy debate preset

Choose the preset that matches your round, then use the timer while practicing speeches and prep. These formats are policy debate presets; check tournament rules if your round uses different times.

05 / Track arguments

Build a speech flow

A .flow file is a multi-sheet speech grid. Move between cells and add rows with keyboard shortcuts:

Tab / Shift+TabMove between cells
Ctrl+Enter / Cmd+EnterAdd a row below
Ctrl+Shift+Enter / Cmd+Shift+EnterAdd a row above

To inspect or edit the saved structure directly, choose JSON source in the flow header.

06 / See the argument structure

Connect an argument map

Open a .canvas file and add the nodes you want to connect. Choose whether a relationship is supporting, answering, or contradicting, choose Connect nodes, then select the source and target nodes.

Connections are stored as standard JSON Canvas edges in the canvas file, so the document remains a regular .canvas file.

See the workspace feature overview for more details on speech documents and flows.
