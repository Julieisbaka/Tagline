Agent access (MCP)

Tagline can share notes with compatible AI clients through its local Model Context Protocol (MCP) server. Open Settings > Integrations > Agent access (MCP) and enable it. Copy the configuration snippet for your client: VS Code (.vscode/mcp.json), Copilot CLI (~/.copilot/mcp-config.json), or Claude Code (use claude mcp add). Claude Desktop requires npx mcp-remote.

The local endpoint is http://127.0.0.1:38419/mcp. Requests use an Authorization: Bearer <token> header; keep the token private.

In Settings > Integrations > Agent access (MCP), you can separately allow note changes and local-model use. Inference tools require the relevant models to be loaded in Tagline; agent requests do not download models.

Available tools:

  • Read: get_status, list_notes, read_note, get_outline, and search_notes.
  • Write: write_note, append_to_note, create_folder, rename_path, and delete_path. Deleting moves the item to the operating system trash.
  • Evidence:
    • list_cards lists evidence cards and citation candidates. Accepts an optional Markdown path, offset, and limit.
    • extract_citation extracts a citation candidate from card Markdown. Accepts text up to 100,000 characters.
    • validate_isbn checks an ISBN-10 or ISBN-13 checksum without looking up a book. Accepts isbn up to 100 characters.
    • audit_evidence finds missing or uncertain citation fields and stale years. Accepts an optional Markdown path, staleYears (1–100), offset, and limit.
  • Local models: local_model_status reports availability; embed_text, summarize_text, and analyze_hypotheses process text supplied by the client with loaded local models. Long input may be truncated; summaries and scores are suggestions, not verified facts.
  • UI: open_note.

The server also uses tagline://note/<path> for note resources. See the Tagline link format below.

Open notes with Tagline links

Right-click a file in the explorer and choose Copy Tagline link to generate an app link. The URI format is:

tagline://note/<path>[#<heading>]
Part Meaning
Scheme tagline, case-insensitive.
Host The action. Only note is supported; it opens a note.
Path A vault-relative note path, with each segment percent-encoded and / as the separator.
Fragment An optional percent-encoded heading to jump to, matched by slug and limited to 200 characters.

For example, tagline://note/Cases/Round%201.md#Plan%20A opens Cases/Round 1.md and jumps to the “Plan A” heading.

URI validation

A URI can be at most 2,000 characters long and must not include a username, password, or port. The path is percent-decoded once, then rejected if it:

  • Is empty.
  • Contains a NUL character or a backslash.
  • Is absolute or starts with a drive letter such as C:.
  • Contains an empty segment or a segment starting with ., including ., .., and hidden files.

Other hosts, such as tagline://settings/x, are ignored. A fragment with invalid percent encoding is dropped, but the note still opens.

Opening behavior

Links open only in the vault that is already open. They never switch vaults, create files, or run commands. If the note is not in the open vault, Tagline shows Link target not found in this vault.

At most 20 links can be queued at once. Links arrive through the operating system: macOS open-url events, or the command line on Windows and Linux.

Local search and analysis models

Download the embedding model in Settings > Integrations to enable semantic or hybrid search. The optional hypothesis-testing and note-summary tools use separate models that run locally after download. These tools are on demand; they do not change the source note.

Tabroom tournaments

Open Settings > Integrations > Open Tabroom, or use the “view and save tournament data” command. Enter a tournament ID or a Tabroom tournament URL containing tourn_id. Public tournament data can be read without signing in; signing in opens the official site in a separate, sandboxed window.

Review the tournament viewer before saving a JSON backup. Backups may contain personal or restricted data, so store and share them carefully. Tagline does not guess missing competitor or team IDs.

OpenCaselist

Open Settings > Integrations > Open OpenCaselist. Sign in on the official site in a separate window. You can browse caselists and disclosed materials, search a selected caselist, and add or edit rounds and citations. Downloaded files go into the current vault; existing files are not overwritten.

Team matching may require identity verification when available details are incomplete or ambiguous. Tagline labels those results rather than treating a name-only match as certain.

Google Docs and Drive

Tagline offers direct Google sign-in and an optional Google Apps Script webhook. Both transfer a note or supported DOCX/HTML file into a new Google Doc in the selected account. Nothing is uploaded until you confirm the transfer. Follow the complete Google Docs setup and transfer guide.

Direct Google sign-in

  1. Open Settings > Integrations > Google Docs / Drive.
  2. Choose Connect Google account and complete authorization in your system browser.
  3. Confirm the account in Tagline, then select that account as the destination when exporting.

Direct sign-in requests identity and per-file Drive access, not unrestricted access to your entire Drive. Credentials are protected in the local app profile, not stored in your vault or note settings.

Apps Script webhook

For a webhook connection, use Set up Google Docs transfer in Settings and follow the step-by-step Apps Script setup. Review the bundled script before authorizing it. Use a unique webhook secret, store it securely, and select the correct executing account and destination folder.

Before connecting: review the scopes, script, and destination account. Disconnecting a saved connection removes its local credentials but does not revoke Google’s authorization grant; manage that grant in your Google Account.

Opening websites

HTTP and HTTPS links open inside Tagline by default. You can turn off Open websites inside Tagline in Settings > Integrations to use your default browser instead. Embedded websites cannot access the vault or app APIs; use an external browser for downloads.

For the complete account setup and transfer flow, continue to the Google Docs guide. App source and releases are available from the Tagline repository.
