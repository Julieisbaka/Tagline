01 Notes & evidence

Build a source-backed case.

A focused guide to writing in Markdown, shaping debate cards, and keeping related research connected inside your vault.

01 / Start with a note

Create a note in your vault

  1. Open the vault
    Choose a folder from the file explorer. A vault is an ordinary folder on your device.
  2. Create or open a Markdown note
    Notes are plain .md files, so they remain readable outside Tagline.
  3. Keep source details nearby
    Use headings to organize claims and include the author, publication, date, and a link or page reference with each piece of evidence.

Files stay portable. Notes are stored in the vault; settings and downloaded local models live in Tagline’s application profile instead.

02 / Write the way you prefer

Choose an editing mode

✎

Visual

Edit formatted Markdown without looking at every syntax marker.

</>

Source

Work directly with literal Markdown and YAML frontmatter.

◉

Read

Review the rendered note without editing its text.

Switch modes from the note header. In Visual mode, use the Properties section to add, edit, and remove YAML frontmatter properties and tags without editing raw YAML. In Read mode, properties are read-only; choose Edit properties in Source to switch to Source mode.

Spellcheck is optional and configured separately for Visual, Source, and Flow editors in Settings > Editors. Right-click an underlined word to choose a suggestion or add it to the dictionary. Manage custom words in the Custom dictionary section of Editors settings.

03 / Make evidence reusable

Format a debate card

In Visual mode, select text and use the formatting toolbar or keyboard shortcuts. The default debate-card shortcuts are configurable in Settings > Keyboard shortcuts:

F4–F7Apply debate-card headings
F8Format citation / bold
F9 · F10Underline · emphasis
F11 · F12Highlight · clear formatting

Mac keyboards may require Fn with function keys. You can change the bindings in Settings rather than relying on the defaults.

A useful card keeps the warrant and source together GRID RESILIENCE

“A diversified portfolio of generation and storage strengthens reliability…”

U.S. Department of Energy, National Transmission Needs Study (2024)

When a card has a DOI, arXiv ID, or ISBN but is missing its title or year, choose Fix with metadata next to the card to fill in the missing source details. Review the metadata before relying on it.

For a complete citation workflow, see Search & citations. To send highlighted evidence to a speech document, see Speech workflows.

04 / Keep ideas connected

Link notes and navigate your research

Wiki links connect notes in the same vault. Use [[Note]] for a note, [[Note#Heading]] for a section, or [[Note|Label]] to show custom link text.

  1. Type [[ in a note to open the link picker.
  2. Use the arrow keys to choose a suggestion, then press Enter.
  3. Confirm with Insert link. Existing heading and label suffixes are preserved when changing the target.

Use backlinks, mentions, tags, an outline, and graph view to find connected material. Press Ctrl+F on Windows/Linux or Cmd+F on macOS to find and replace text in the current note; replacements can be undone.

To link to a note from outside Tagline, right-click its file in the explorer and choose Copy Tagline link. A link such as tagline://note/Cases/Round%201.md#Plan%20A opens the note and jumps to its “Plan A” heading. Links only open notes in the vault already open; they never switch vaults or create files. See the Tagline URI format and rules.

05 / Reuse and protect your work

Use templates and revision history

Put reusable Markdown files in your template folder (Templates/ by default; change it under Settings > General > Templates). Tagline can replace these placeholders:

  • {{date}} and {{time}} — current local date and time. Add a format such as {{date:dddd, MMMM D}} or {{time:hh:mm A}}; wrap literal text in [brackets]
  • {{title}} and {{path}} — target note title and vault-relative filename
  • {{content}} and {{properties}} — note body and raw YAML properties. {{properties}} expands only in Create new note from template; it is empty when inserting or applying, so bare YAML never lands in a note body
  • {{cursor}} — where the cursor lands after Apply template to current note

Insert template at cursor inserts only the template body and warns if the template had YAML frontmatter. Apply template to current note merges template properties into the note's frontmatter (existing keys are kept) and lets you keep, append, or replace the body. Create new note from template keeps the full frontmatter and lets you pick the target folder.

Revision history is available from the note header and stored in .tagline/history inside the vault. Adjust retention under Settings > Files and folders. Back up the vault like any other important folder.

Keyboard bindings can be customized in Settings > Keyboard shortcuts. See also the workspace overview.
