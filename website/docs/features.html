Looking for a specific task? Step-by-step guides cover notes and evidence, search and citations, and speech workflows.

Vaults and notes

A vault is a folder on your device. Notes are Markdown files; speech grids use .flow files; visual canvases use .canvas files in the standard JSON Canvas format. Settings and downloaded models live in the app profile, not in the vault.

Replay the onboarding tour in Settings > Advanced settings > Internal flags > Show onboarding again.

Revision history is stored in .tagline/history inside the vault; change retention in Settings > Files and folders. Canvas history can save exact JSON and layout (Complete) or content changes without movement-only revisions (Data). If a flow or canvas becomes invalid, restore the most recent valid save when recovery is offered. Recovery skips broken revisions, saves the current source to history, and persists the restored document.

Write and organize notes

Choose Visual, Source, or Read in a note header to edit formatted Markdown, edit its literal source, or read the rendered note. YAML frontmatter stores properties; the Properties section lets you edit them in Visual mode. Wiki links support [[Note]], heading links such as [[Note#Heading]], and custom labels such as [[Note|Label]].

Use backlinks, mentions, tags, an outline, or graph view to navigate a vault. Reusable Markdown templates can include placeholders such as {{date}}, {{title}}, and {{path}}. Find and replace text in a note with Ctrl+F on Windows/Linux or Cmd+F on macOS.

Templates in Templates/ can also use {{time}}, {{content}}, and {{properties}}. The path is the target note's vault-relative filename including .md; content is the Markdown body without frontmatter; properties are the raw YAML without delimiters, preserving comments and formatting. Placeholder values are inserted literally, not expanded recursively.

Debate-card shortcuts are configurable in Settings > Keyboard shortcuts: F4–F7 apply card headings, F8 citation/bold, F9 underline, F10 emphasis, F11 highlight, and F12 clears formatting. Mac keyboards may need Fn with function keys.

Sidebar shortcuts and file-explorer toolbar/status items can be reordered or hidden. Drag to reorder; use the available up/down controls for keyboard-accessible shortcut ordering. Restore defaults even if all toolbar items are hidden. All panels and dialogs are keyboard-navigable; opening moves focus into the surface, and closing it restores focus to the control that opened it. Checkup completion and link-check results are announced through live regions for assistive technology.

Find and cite evidence

Open vault search with Ctrl+Shift+F or Cmd+Shift+F. For semantic or hybrid search, download the local embedding model from Settings > Integrations.

Choose Create citation from a note, the command palette, or the File menu. Enter source details or paste a public URL/DOI to autofill, then copy the Markdown citation or insert it into the current note.

Prepare speeches and flows

Send selected or highlighted evidence to the active speech document with Ctrl+Shift+S or Cmd+Shift+S. Tagline estimates speaking time from highlighted evidence and citations. Personal speech calibration in Settings > General can tune estimates from your own timed samples.

Mark a Markdown document as a speech document with the Set as speech doc file action. A new speech document uses this frontmatter:

---
speech: true
---

Flows are multi-sheet speech grids. Use Tab and Shift+Tab to move between cells. Use Ctrl+Enter/Cmd+Enter to add a row below, and add one above with Ctrl+Shift+Enter/Cmd+Shift+Enter. In a canvas, connect arguments as supporting, answering, or contradicting one another.

The timer includes speech and affirmative/negative prep clocks for policy debate’s high-school 8-3-5 and college 9-3-6 presets.

Import and export

Standalone HTML export is built in. Other formats use the separately installed Pandoc; PDF export also requires a LaTeX engine. DOCX, ODT, RTF, HTML, and EPUB can be converted to Markdown for review before saving. See the Google Docs transfer guide for account setup and upload details.

HTTP and HTTPS links open inside Tagline by default. Turn off Open websites inside Tagline in Settings > Integrations to use your default browser. Embedded sites cannot access the vault or app APIs; use an external browser for downloads.
