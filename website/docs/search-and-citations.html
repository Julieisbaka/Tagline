02 Search & citations

Find the source. Keep the trail.

Search your vault or scholarly metadata, optionally add local meaning-based results, and turn source details into citations you can reuse.

01 / Find what you have

Search your vault

  1. Open vault search
    Press Ctrl+Shift+F on Windows/Linux or Cmd+Shift+F on macOS.
  2. Search across your notes
    Use a phrase, claim, source name, or tag to locate relevant files.
  3. Open a result and check its context
    Review the surrounding argument and source details before reusing evidence.

For exact terms and known wording, start with regular vault search. Semantic search is optional and requires a one-time local model download.

02 / Search by meaning

Add semantic or hybrid search

  1. Open Settings > Integrations.
  2. Download the local embedding model.
  3. Return to vault search and use semantic or hybrid search for concepts that may be phrased differently in your notes.

Local model, local files. The embedding model runs on your device after download. Tagline stores your research as files in the vault.

Semantic search complements keyword search; verify a result in its note before treating it as evidence.

03 / Find scholarly sources

Search scholarly works and cut a card

  1. Open search
    Press Ctrl+Shift+F on Windows/Linux or Cmd+Shift+F on macOS, then choose Scholarly (Crossref) as the search mode.
  2. Find a source
    Enter a query and press Enter or choose Search Crossref. Open a result's source to review it.
  3. Cut a card
    Choose Cut card, review and complete the prefilled citation, and enter a card tag. Paste an excerpt from the source that you have permission to use.
  4. Save to the vault
    Choose Save card to vault to create and open a Markdown note containing the tag, citation, and excerpt.

Crossref, not JSTOR. Search sends your query to Crossref and returns scholarly metadata; it does not search JSTOR directly or provide access to paywalled full text. Some results may be missing citation details, so check the source and fill them in before saving.

04 / Make a source traceable

Create a citation

Start from a note, the command palette, or the File menu. The command palette includes a citation preview before you choose a citation action:

  1. Choose Create citation
    The citation form opens without replacing the current note.
  2. Enter source details
    Fill in the available author, title, publication, date, and locator fields.
  3. Paste a citation in one step
    Choose Paste citation to extract citation details from the clipboard and fill the citation editor.
  4. Autofill when you have a public identifier
    Paste a public URL or DOI, then choose Autofill from URL. Review the returned details for accuracy.
  5. Copy or insert
    Copy the Markdown citation, or insert it into the current note.

Keep the citation with the claim it supports. For keyboard formatting and evidence-card structure, see Format a debate card.

05 / Optional analysis

Test a claim or summarize a note

Tagline includes optional, on-demand local analysis tools:

  • Test a hypothesis compares selected text, a card, or a note with one or more hypotheses. Download the Political DEBATE model from Settings > Integrations before using it.
  • Summarize opens a summary dialog for a Markdown note. Download the summary model from Settings > Integrations.

Review, don’t replace. These tools are on demand, run locally after their models are downloaded, and do not change the source note. Check any generated summary or analysis against the underlying evidence.
