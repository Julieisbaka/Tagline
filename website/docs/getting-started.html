Install the app

Download the latest release for your computer from GitHub. Tagline currently publishes desktop builds for Windows and macOS; choose the installer that matches your platform.

View the latest release ↗

First launch: release builds are unsigned and not notarized, so Windows or macOS may show an operating-system security warning. Tagline can check for, download, and install updates from Settings; updates are not installed without your confirmation.

Open a vault

A vault is an ordinary folder. Choose a folder you already use for research, or create the sample vault from Tagline’s welcome screen. Your Markdown notes, .flow speech grids, and .canvas argument maps stay in that folder.

Settings and downloaded local models are kept in the application profile rather than in the vault. Keep backups of both your vault and important app-profile data.

Keep Tagline up to date

  1. Open Settings > Installation and choose Check for updates.
  2. If an update is available, choose Download update. Tagline verifies the download against the release checksum.
  3. On Windows, choose Install update and restart; Tagline saves pending edits before restarting. On macOS, choose Open installer, quit Tagline, then replace the app in Applications with the one from the opened disk image.

Update checks and installation are user-initiated, and in-app downloads are available in packaged installations when a compatible release is published. If no compatible download is offered, install the release manually. Keep the existing app ID, product name, install scope, and profile so the updated app can find your existing settings. Back up your profile and vaults first; do not remove the profile when updating.

Run from source

For development, clone the project and use the repository’s npm scripts:

npm install
npm run dev      # start the development app
npm start        # build and launch
npm run package  # package for this operating system

Ready to use your vault? Continue with writing notes and building evidence, or jump to finding and citing research.
