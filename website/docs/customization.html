Appearance settings

Choose the language, built-in light or dark themes, fonts, and editor preferences in Settings > Appearance. Tagline includes high-contrast themes and respects reduced-motion preferences. Optional custom CSS is available from appearance settings.

Create a theme

Themes are JSON color palettes with optional CSS custom-property overrides. Start with a built-in theme, choose Customize current theme, and adjust the palette. Export the result as JSON to keep or share it; import a JSON theme to apply it.

Tagline validates imported themes and displays import errors instead of partially applying invalid files. See the theme format reference for supported colors, variables, metadata, limits, and schema usage.

Install an extension

To install a community extension, open Settings > Extensions > Browse extensions, select Browse registry, review the listed permissions, and choose Install. Registry extensions are listed through pull requests to the extension registry; see Browse and publish extensions. To install from a local folder:

  1. Open Settings > Extensions > Open extensions folder.
  2. Add an extension folder with a manifest.json and its referenced files.
  3. Choose Reload extensions, review the requested permissions, then enable the extension.

Extensions can contribute commands, ribbon shortcuts, settings, themes, sidebar panels, and dialogs. Entry scripts run in a sandboxed worker through the supplied Tagline API; they do not have access to the app’s DOM or Node.js. Review permissions and extension code before enabling an extension.

Extensions that declare review-gated capabilities require approval of the current manifest before they can be enabled. If a reviewed manifest changes, its approval is invalidated and the extension remains disabled until reviewed again. See Review before enabling for details.

See the Extension API reference for the manifest, permission model, JavaScript bridge, vault access, and UI contributions.

Extensions can store encrypted credentials with the review-gated secrets permission. To remove an extension's saved secrets, select Clear stored secrets on its card in Settings > Extensions. Disabling the extension blocks access but does not delete its secrets.

Schemas and examples

The repository includes JSON Schemas for speech flows, themes, extension manifests, the extension registry, and exported extension settings. Canvases follow the standard JSON Canvas format. Use the schemas to validate your files or enable editor completion, and see the demo extension for a working example.
