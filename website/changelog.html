0.1.0 In development

This release is still in development, so these notes may change before it is published.

Added

  • Settings > Extensions > Browse extensions lists community extensions from the extension registry and installs or updates them from GitHub with per-file integrity checks. Authors submit extensions by pull request.
  • Extension manifests can declare authors and a sourceUrl, shown on the extension card with a View source button.
  • Extension settings add encrypted secret fields, bounded array/object values, linked descriptions, and vault-relative path values.
  • Extensions can publish bounded source- and visual-editor diagnostics with severity styling and hover messages.
  • Accessibility settings add opt-in interaction sounds for opening notes, tabs, saving, and errors.

Improved

  • Card detection removes incomplete HTML delimiters from card titles, keeping malformed markup out of the displayed title.
