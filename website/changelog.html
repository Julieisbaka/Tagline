Changelog

Release notes for Tagline, with the newest version first.

Unreleased

0.1.1 In development

This release is still in development, so these notes may change before it is published.

Added

  • Vault migration backups avoid name collisions and migration artifacts can be cleaned up from the vault manager.
  • Extensions can read files from their own installed folder in the sandbox via tagline.extension.readFile(), and manifests can declare engines.tagline for version compatibility checks.
  • Version-incompatible extensions can be force-enabled from Settings after a warning confirmation.

Fixed

  • Timer microphone auto-start debounces threshold changes, persists the threshold per profile, and avoids false starts during microphone permission prompts.
  • Scholarly search retries failed metadata requests and normalizes DOI/URL extraction edge cases.
  • Citation extraction and metadata handling better recognize DOI variants, normalize URLs, and preserve balanced nested parentheses in extracted links and identifiers.
  • Search query parsing supports quoted phrases and -exclude terms/phrases while keeping plain-text matching safe.
  • Broken enabled extensions are automatically disabled after load failures instead of repeatedly crashing startup flows.
  • Flow Markdown preview cache invalidates on theme/font changes, caps memory, and avoids stale rendered output.
  • Spellcheck context menus are handled more reliably for editable targets and avoid flow spellcheck suggestion races.
  • Spanish localization is completed for currently used interface strings.

Released

0.1.0

Added

  • Settings > Extensions > Browse extensions lists community extensions from the extension registry and installs or updates them from GitHub with per-file integrity checks. Authors submit extensions by pull request.
  • Extension manifests can declare authors and a sourceUrl, shown on the extension card with a View source button.
  • Extension settings add encrypted secret fields, bounded array/object values, linked descriptions, and vault-relative path values.
  • Extensions can publish bounded source- and visual-editor diagnostics with severity styling and hover messages.
  • Accessibility settings add opt-in interaction sounds for opening notes, tabs, saving, and errors.
  • Search scholarly works through Crossref and turn reviewed source metadata into evidence cards.
  • Delivery analytics estimate filler words and speaking rates in practice transcripts, with saved statistics for comparing speeches over a season.
  • Timers can start automatically when speech is detected, with adjustable microphone sensitivity and an optional floating timer.
  • Extensions can contribute reusable templates and package fonts and translations as declarative assets.
  • Older vaults can be upgraded through a guided migration wizard with validation and recovery support.

Improved

  • Card detection removes incomplete HTML delimiters from card titles, keeping malformed markup out of the displayed title.
  • Smart paste recognizes common evidence-card leads and preserves supported rich-text formatting from other editors.
