Changelog

Release notes for Tagline, with the newest version first.

In development

0.2.0 In development

Improved

  • Extension panels and webviews now receive live updates when Tagline's reduced-motion settings change.
  • Scholarly Search is now a bundled, optional core plugin with its own Core Plugins settings section. Its standalone extension source is also available in the registry.
  • Timer progress, selected speech, and prep time now survive panel remounts and app restarts. Restored timers remain paused until you start them again.
  • The floating timer remembers its last position between launches.

Fixed

  • The Research tools dialog keeps scan actions, background checks, and cite extraction controls organized without overflowing.
  • Setting help descriptions are no longer clipped at the bottom of their settings group.

Removed

  • The experimental delta revision history setting and writer have been removed. Documents now always save full snapshots, while revisions previously stored as deltas remain readable.
  • Delivery analytics has been removed, including the transcript analysis dialog, saved speech statistics, command palette action, and related documentation.
  • Pins and favorites are no longer migrated from the old browser-storage format. They are now read only from .tagline/pins.json, so pins that were never migrated by an earlier version will not appear.

Deprecated

The following are deprecated and planned to be removed in a future version.

  • French (fr) interface translations are deprecated. French remains available for now, but English and Spanish will be the supported languages in a future release. A notice appears when French is selected.
  • Extracting inline Markdown tags with extractTags() is deprecated. Use extractMetadataTags() to read structured tags instead.
  • Calling detectCards() without a depth or weak option, which returns the legacy result shape. Pass an explicit option to get the full result shape.
  • Automatic migration of extension data from plain browser storage into encrypted extension storage. Open each extension once on this version to migrate its data before the migration is removed.

Released

0.1.6

Added

  • Flow cell text is now included in global search and the link index. Sheet and column names rank as headings, and links and tags written in cells produce backlinks just like notes.
  • Opening a flow from search now takes you to the matched cell, not just the file.

Fixed

  • Wiki links ([[Card]]) inside flow cells are now clickable and resolve to the linked note, so links found through search backlinks are no longer dead ends.
  • Right-click → Paste cells in the flow grid now reports clipboard and malformed cell-data errors the same way Ctrl+V does, instead of leaving a console rejection. Clipboard reads also use the same Electron IPC path as copies when available.
  • Opening several .flow files from the OS at once no longer strands the remaining files in the queue when one of them fails to open.
  • Typing in a flow cell is saved as one undo step when you leave the cell, instead of one per keystroke, so Ctrl+Z no longer needs a press for every character.
  • Switching flow sheets starts the cursor at the first cell of the new sheet, rather than keeping the position from the previous sheet.
  • Flow columns with a blank name no longer use the negative side color.
  • Deleting the last row in a flow sheet is blocked, so a sheet always keeps at least one row.

Released

0.1.5

Canvas improvements and fixes.

Added

  • Canvas edits can now be undone and redone with the standard shortcuts (Mod+Z and Mod+Shift+Z), using a bounded snapshot history that is discarded when the canvas changes outside the editor.

Improved

  • Canvas node callbacks are stable across edits, so memoized nodes no longer re-render on every mutation.
  • Typing in a canvas text node keeps a local draft and commits it on blur or save, instead of revalidating and serializing the whole canvas on every keystroke.

Fixed

  • Dragging the canvas minimap no longer also pans the canvas underneath it.
  • Canvas file nodes now follow note and folder renames instead of turning into broken cards.
  • Canvas next/previous selection now starts at the first or last item when nothing is selected.
  • Canvas context menu labels are translated.
  • Clearing a Canvas file node subpath no longer blocks saving until re-entered.
  • Canvas edge arrow markers use stable IDs so colors stay correct after edits.

Released

0.1.4

Improved

  • Vault .taglineignore patterns now handle backslash escapes and trailing whitespace more like Git: escaped characters are literal, and only trailing spaces are trimmed.
  • Link-rot monitor persists the last-checked time before returning when there are no cited URLs.
  • Timer microphone meter state updates are throttled to about 10 fps.
  • Non-Latin headings (e.g. Chinese, Japanese) now produce stable anchor slugs instead of colliding on empty IDs, so [[Note#Heading]] links work.
  • Revision history now uses a <select> element so arrow keys can page through saved versions without needing to click first.

Fixed

  • Flow grid no longer remeasures every cell on each edit; it resizes only when row/column counts or relevant settings change.
  • Case-only note renames preserve revision history instead of deleting it.
  • Invalid citation URLs show a friendly error instead of a raw TypeError.
  • Concurrent extension installs no longer overwrite each other's install tokens; either load can complete the installation.
  • Extension settings reset clears secrets before non-secret settings, so a failed secret clear cannot leave a partial reset.
  • MCP agent access to the vault now follows and validates the same symbolic-link containment rules as the rest of the app.
  • Tab effects subscribe to stable tab members (error, clearError, openPath) instead of the recreated tabs object.

Released

0.1.3

Improved

  • Pinned notes and folders show a pin marker in the file explorer tree.
  • Opening a vault drops pinned entries whose files no longer exist, instead of keeping them in .tagline/pins.json forever.
  • Keyboard shortcut lookups use a precomputed map instead of copying and scanning all built-in bindings on every lookup.
  • Canvas editor adds an optional minimap, viewport culling for large canvases, keyboard node/edge selection, and arrow-key nudging of selected nodes (hold Shift for larger steps).
  • Flow grid cells use a single roving tab stop, so Tab reaches preview cells directly; focus rings match edit mode and an “Enter to edit” hint marks the focused cell.

Fixed

  • Pin state is stored only in .tagline/pins.json; the legacy localStorage copy is migrated once and then purged, so stale entries no longer reappear after clearing pins.
  • Pinned tabs and pinned notes share a single bookkeeping path; closing a pinned tab unpins it.
  • Fixed: pins.json no longer rewrites on every tab close when the path wasn't pinned.
  • Fixed: read failure no longer blocks tab restoration and write persistence.
  • Fixed: pins writes now retry on EBUSY/EPERM (Windows file-lock hazard).
  • Fixed: flow cells can be opened and edited with a primary click in Visual mode.
  • Fixed: canvas [[#Heading]] links resolve to the canvas file instead of being dropped, and plain link paths containing | are no longer split into destination and label.
  • Fixed: canvas nodes and connections with broken links show a clear in-node message and a toolbar count.

Released

0.1.2

Improved

  • Vault path checks follow symbolic links and reject targets outside the vault, including dangling links.
  • Vault migrations write the manifest atomically and recover the newest backup when a migration journal is corrupt.
  • Window close and update-save handshakes ignore messages from subframes, and startup failures show an error dialog instead of exiting silently.
  • Extension permission reviews include the extension version, so version updates require a fresh review.
  • Migration backup cleanup now validates the vault the same way as other recent-vault operations.
  • Extension write and append operations wait for pending edits to reach disk before resolving.
  • Command palette search now ranks word starts, prefixes and contiguous matches higher, matches punctuation-insensitive queries, and finds commands by their shortcut.
  • File tabs show a dirty dot, a pulsing saving indicator, a brief saved flash, and a persistent error marker.
  • Folders can be pinned from the file explorer; pinned folders sit alongside pinned notes and jump to their place in the tree.
  • Pinned notes, folders and file tabs are saved inside the vault in .tagline/pins.json, so they survive profile loss and travel with the vault.
  • Tabs can be pinned from their context menu; pinned tabs reopen with the vault, even when workspace tab saving is disabled.
  • An optional setting boosts pinned notes and folders in the quick switcher. It is off by default.
  • Timer preset dialogs can copy a preset as JSON and paste one back.

Fixed

  • Deleting a file or folder now confirms that it was moved to the trash.
  • The embedded browser opens the requested URL when the view is first created.
  • Update checks no longer fail when a locked installer folder cannot be cleaned up.
  • Saving no longer plays the save sound when there was nothing to save, and a successful unload flush no longer reports an error.
  • Editor toolbar find and send-card actions handle a missing editor view without throwing.
  • Opening and closing tabs in the same tick no longer drops or restores stale tabs.
  • Reloading extensions clears surfaces left behind by disposed extension hosts.
  • Hypothesis and summary dialogs ignore repeated runs while one is already in progress.
  • Cursor statistics are debounced instead of updating app state on every keystroke.
  • The graph simulation stops rendering once it settles and resumes on interaction or content changes.
  • Closing without a registered save handler logs a diagnostic warning before falling back to the renderer unload handler.

Released

0.1.1

Added

  • Vault migration backups avoid name collisions and migration artifacts can be cleaned up from the vault manager.
  • Advanced settings include a (currently no-op) developer mode toggle.
  • Extensions can read files from their own installed folder in the sandbox via tagline.extension.readFile(), and manifests can declare engines.tagline for version compatibility checks.
  • Version-incompatible extensions can be force-enabled from Settings after a warning confirmation.

Improved

  • Release builds no longer emit source maps.
  • Electron release packages exclude tests and documentation.

Fixed

  • Timer microphone auto-start debounces threshold changes, persists the threshold per profile, and avoids false starts during microphone permission prompts.
  • Scholarly search retries failed metadata requests and normalizes DOI/URL extraction edge cases.
  • Citation extraction and metadata handling better recognize DOI variants, normalize URLs, and preserve balanced nested parentheses in extracted links and identifiers.
  • Search query parsing supports quoted phrases and -exclude terms/phrases while keeping plain-text matching safe.
  • Broken enabled extensions are automatically disabled after load failures instead of repeatedly crashing startup flows.
  • Flow Markdown preview cache invalidates on theme/font changes, caps memory, and avoids stale rendered output.
  • Spellcheck context menus are handled more reliably for editable targets and avoid flow spellcheck suggestion races.
  • Spanish localization is completed for currently used interface strings.
  • Corrupt or unreadable settings files are backed up and surfaced with a one-time startup warning instead of being reset silently.

Released

0.1.0

Added

  • Settings > Extensions > Browse extensions lists community extensions from the extension registry and installs or updates them from GitHub with per-file integrity checks. Authors submit extensions by pull request.
  • Extension manifests can declare authors and a sourceUrl, shown on the extension card with a View source button.
  • Extension settings add encrypted secret fields, bounded array/object values, linked descriptions, and vault-relative path values.
  • Extensions can publish bounded source- and visual-editor diagnostics with severity styling and hover messages.
  • Accessibility settings add opt-in interaction sounds for opening notes, tabs, saving, and errors.
  • Search scholarly works through Crossref and turn reviewed source metadata into evidence cards.
  • Delivery analytics estimate filler words and speaking rates in practice transcripts, with saved statistics for comparing speeches over a season.
  • Timers can start automatically when speech is detected, with adjustable microphone sensitivity and an optional floating timer.
  • Extensions can contribute reusable templates and package fonts and translations as declarative assets.
  • Older vaults can be upgraded through a guided migration wizard with validation and recovery support.

Improved

  • Card detection removes incomplete HTML delimiters from card titles, keeping malformed markup out of the displayed title.
  • Smart paste recognizes common evidence-card leads and preserves supported rich-text formatting from other editors.
