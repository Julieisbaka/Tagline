These are defaults. <kbd>Mod</kbd> means <kbd>Ctrl</kbd> on Windows/Linux and <kbd>Cmd</kbd> on macOS. Your settings may differ. Some actions, including creating a flow or canvas, have no default shortcut: find them in the command palette or assign one.

## Customize shortcuts {#customize}

1. Open **Settings &gt; Keyboard shortcuts**. Actions are grouped by application, note editing, flow editing, canvas editing, and extensions.
2. Select the shortcut button for an action and press the desired combination. Changes save automatically; the settings screen reports unsupported, reserved, or conflicting combinations.
3. Use **Clear** or press <kbd>Delete</kbd> / <kbd>Backspace</kbd> while recording to remove a binding. <kbd>Escape</kbd> normally cancels recording; the flow deselect action can itself use Escape.

Use **Reset all shortcuts** to restore defaults. Most plain unmodified keys cannot be assigned; function keys and certain flow navigation keys are exceptions. Check the command palette when an action is unbound or a shortcut is unavailable.
